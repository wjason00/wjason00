# Jason Wang

I'm a Neuroscience BSc student at UCL, interested in computational models of the brain and machine learning. My projects span developmental modelling, EEG evaluation and scientific software.

## Selected work

- **[MorphBrain](https://wjason00.github.io/demos/morphbrain/)** — Exploring how molecular patterning could shape brain growth and folding. I implemented reaction–diffusion components and compared SHH/BMP conditions. The current demo shows the patterning stage; coupled 3D growth and folding remain a development aim.
- **[Model Morpher](https://github.com/wjason00/model-morpher)** — A Python desktop tool for generating and inspecting transitions between 3D meshes without matching their vertices. It uses signed-distance interpolation and surface reconstruction.
- **[EEG decoder evaluation](https://docs.google.com/presentation/d/1nk-tRbrmjyU5FfJhQrmNkPdnxmlSUcTThhmaOk1nU8k/present)** — Our g.tec BR41N.IO team asked whether early calibration could select between CSP and Riemannian EEG decoders at a fixed decision time. I shared evaluation work through pull requests and relayed the organisers' scoring rules. At 60 calibration trials per session, selection did not beat fixed CSP in a retrospective comparison using previously inspected later trials. The link opens the team's presentation.
- **[Neural simulation study](https://wjason00.github.io/demos/fly/)** — I proposed and directed a sensitivity study of a published fly connectome model, testing whether a disconnection effect persisted as assumed connection strength changed.

I'm interested in research placements and paid internships involving brain modelling, machine learning or scientific software.
